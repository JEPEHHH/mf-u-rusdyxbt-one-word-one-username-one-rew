# One Word, One Username, One Reward

Entry for the make.fun contest. The program writes one single-word username to
`/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Run

    python3 main.py

No packages, no keys, no network: standard library only. The program checks
the word against the gate (1-30 characters, no whitespace) before writing it.
